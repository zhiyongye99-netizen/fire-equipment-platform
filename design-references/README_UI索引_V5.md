# UI 参考图索引 V5

## 使用原则

1. UI 图只作为布局、风格、信息密度、模块优先级参考。
2. 图片中文字可能不准确，最终字段以 docs/、API 文档、数据库模型为准。
3. 手机端必须低密度，避免复杂表格和过小文字。
4. 供应商大量录入必须放 PC 后台，小程序只做轻工作台。
