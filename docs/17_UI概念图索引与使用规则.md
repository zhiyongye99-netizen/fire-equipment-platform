## 使用规则

1. 图片是视觉参考，不是最终文案来源。
2. 图片中的字段、参数、价格、品牌仅作示意。
3. 最终开发以 docs/ 下的 PRD、页面清单、数据字典、接口文档为准。
4. Codex 开发前端时应参考这些图片的信息密度、字号和布局。
5. 小程序端必须优先保证真实手机可读性。
