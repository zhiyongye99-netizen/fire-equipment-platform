# 供应商资料分级与冷启动策略

## 供应商会担心什么

供应商不会一开始就愿意上传完整资料，因为可能涉及商业机密、竞争策略、报价体系、客户关系和渠道布局。

敏感资料包括：

- 完整技术参数；
- 报价表和底价；
- 未公开客户名单；
- 新品方案；
- 检测报告高清原件；
- 渠道和售后网络细节。

## 分级资料体系

| 级别 | 内容 | 是否要求 | 展示方式 |
|---|---|---|---|
| L1 基础公开资料 | 企业名称、产品名称、公开参数、主图 | 必须 | 公开展示 |
| L2 增强资料 | 彩页、服务区域、案例摘要 | 推荐 | 审核后展示 |
| L3 合规证明 | 认证证书、检测报告、授权书 | 部分必填 | 可选择公开/申请后可见/仅平台审核 |
| L4 敏感商业资料 | 报价底线、客户名单、内部方案 | 不采集 | 不进入平台 |

## 字段可见范围

| 可见范围 | 示例 |
|---|---|
| 公开展示 | 产品名称、主图、基础参数 |
| 消防认证用户可见 | 产品彩页、配置摘要 |
| 申请后可见 | 检测报告、说明书、详细配置 |
| 仅平台审核可见 | 营业执照、完整证书、授权书 |
| 不采集 | 报价底线、未公开客户名单 |

## 冷启动策略

不要指望供应商从 0 主动上传全量资料。

推荐模式：

```txt
平台用公开资料预建基础产品库
↓
邀请供应商认领产品
↓
供应商补充资料
↓
平台审核
↓
获得认证标识和线索权益
```

## 交换条件

| 供应商行为 | 获得权益 |
|---|---|
| 完成认证 | 认证标识 |
| 补全产品资料 | 更高展示权重 |
| 上传证书 | 资料完整标签 |
| 上传案例 | 案例展示入口 |
| 及时响应线索 | 排序权重提升 |
| 购买会员 | 更多产品数、线索额度、数据看板 |

## 产品设计要求

供应商后台必须给供应商控制感：每个资料都可选择可见范围，不能默认全公开。
