# 跨行业复制与边界

## 结论

消防项目跑通后，底层模式可以迁移，但不能“几乎直接复刻”。

可复制的是：

```txt
专业目录库 + 参数模板库 + 合规资料库 + 历史采购/中标参考 + 供应商认证 + 用户需求线索 + 采购前决策辅助
```

必须重做的是：

```txt
行业分类、行业标准、监管规则、供应商资质、内容审核边界、商业化规则
```

## 适合迁移顺序

```txt
消防车辆装备
↓
应急救援装备
↓
防汛排涝装备
↓
城市应急/市政抢险装备
↓
水务设备
↓
电力设备
↓
医疗器械
↓
药品/耗材
```

## 不同方向难度

| 行业 | 迁移难度 | 判断 |
|---|---|---|
| 应急救援 | 低到中 | 与消防高度相近 |
| 防汛排涝 | 低到中 | 场景化、装备化明显 |
| 水务/市政 | 中 | 品类广，需聚焦设备场景 |
| 电力 | 中高 | 官方供应链体系强 |
| 医疗器械 | 高 | 监管、医保、药监、院内流程复杂 |
| 药品耗材 | 很高 | 不建议早期进入 |

## 复制前门槛

消防样板至少应达到：

- 100 家有效供应商；
- 1000 个结构化产品；
- 1000 名专业用户；
- 每月稳定有效线索；
- 有中标价格、参数、案例闭环；
- 有供应商会员或线索收入。
