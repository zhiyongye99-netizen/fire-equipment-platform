# 15_资料库管理建议

## 核心原则

2G 原始资料不要放进代码仓库，也不要全部交给 Codex。原始资料、结构化数据、开发仓库必须分开。

## 推荐结构

消防装备平台资料库/

- 01_供应商资料
- 02_产品彩页
- 03_招标文件
- 04_中标公告
- 05_政策标准
- 06_内部参考资料
- 07_展会资料
- 08_图片视频素材
- 99_待整理

## 资料分级

| 等级 | 含义 | 使用方式 |
|---|---|---|
| A | 公开资料 | 可用于公开展示，注明来源 |
| B | 授权资料 | 可用于产品页或供应商主页 |
| C | 内部参考 | 只提取结构化字段，不公开原文 |
| D | 敏感资料 | 不进入 Codex，不进入公开平台 |
| E | 待判断 | 暂不使用 |

## 进入代码仓库的内容

只放结构化结果：装备分类表、参数模板表、产品样例、资料索引样例、招采样例。
