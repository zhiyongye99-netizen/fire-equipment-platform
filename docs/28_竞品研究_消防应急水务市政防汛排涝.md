# 竞品研究：消防、应急救援、水务、市政、防汛排涝

## 总结判断

这些行业都有竞品，但大多数集中在：

1. 官方采购/交易平台；
2. 政府电子卖场；
3. 标讯/招采数据平台；
4. 工业品/MRO 平台；
5. 行业媒体/黄页/展会平台；
6. 厂商官网/经销商私域。

空白层是：

> 采购前调研阶段的产品参数库、横向比选、中标参考、用户评价、供应商线索。

## 官方平台

中国政府采购网、全国公共资源交易平台、各省市政府采购网和公共资源交易中心是权威公告和交易信息来源，但它们通常不做产品级参数库、实战评价、供应商线索闭环。

## 工业品/MRO 平台

京东工品汇、震坤行、西域、固安捷等对通用标准品有优势，例如普通安全防护、工具、泵阀、仪表等。

你的项目不应做普通工业品商城，应避开标准品电商竞争，聚焦消防车辆、排涝装备、水域救援、无人装备、通信指挥、特种救援装备。

## 消防方向

现有平台多为公告、认证查询、行业黄页、企业官网、展会平台。缺少成熟的“消防版汽车之家 + 参数比选 + 中标参考 + 消防圈评价 + 供应商线索”。

## 应急救援方向

品类更宽，包括地震、水域、危化、森林、通信、无人机、机器人、生命探测、洗消、照明等。现有信息碎片化，适合做场景化选型。

## 水务方向

公告和招采平台较成熟，但设备级参数比选、运维评价、全生命周期成本展示不足。应聚焦泵站设备、管网检测、在线监测、应急抢修装备。

## 市政方向

范围太宽，不建议做“市政采购大全”。应聚焦市政应急抢险装备、城市内涝排水、管网检测与修复、桥隧应急处置、城市生命线监测。

## 防汛排涝方向

消防之后最值得优先复制。参数适合结构化：排水能力、扬程、通过粒径、动力形式、机动方式、部署时间、作业环境、配套设备、维保要求。

## 差异化模块

1. 场景化装备选型；
2. 参数模板库；
3. 中标价格参考；
4. 供应商资料分级；
5. 专业用户评价与案例；
6. 采购前报告。
