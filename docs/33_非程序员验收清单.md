# 非程序员验收清单

## 每次 Codex 完成任务后，你必须问

1. 改了哪些文件？
2. 如何运行？
3. 如何打开微信开发者工具验收？
4. 是否通过 lint/typecheck/test？
5. 哪些地方是 mock 数据？
6. 哪些地方需要我人工确认？
7. 有没有权限和敏感数据风险？

## 小程序页面验收

| 项目 | 标准 |
|---|---|
| 页面打开 | 不白屏、不报错 |
| 字体 | 手机上清楚，正文不低于 28rpx |
| 按钮 | 手指容易点，主按钮 72–88rpx |
| 胶囊避让 | 右上角不遮挡 |
| 列表 | 每屏 2–3 个产品卡片 |
| 空状态 | 没数据时有提示 |
| 加载状态 | 接口慢时有 loading |
| 错误状态 | 接口失败时有提示 |
| 真机 | 手机微信扫码可用 |

## 供应商权限验收

- 未认证供应商不能发布产品；
- 供应商只能看自己的线索；
- 手机号默认脱敏；
- 供应商敏感资料不能默认公开；
- 驳回原因只给对应供应商看。

## 平台后台验收

- 供应商审核有通过/驳回；
- 产品审核有通过/驳回；
- 所有审核有操作日志；
- 管理员权限不能暴露在前端；
- 删除操作有确认和记录。

## 数据验收

- 产品必须有 category_id；
- 产品必须绑定 supplier_id；
- 参数必须结构化；
- 中标数据要保留来源字段；
- 文件只存 URL，不直接存数据库。
