# 成本与工具选择：Claude / Codex / Antigravity

## 结论

低价订阅可以帮助你启动项目、搭骨架、做 MVP，但不能保证独立完成一个可正式商用、安全上线的完整系统。

## AI 工具适合做什么

- 阅读项目文档；
- 生成项目骨架；
- 写数据库模型；
- 写 API 初版；
- 写页面初版；
- 修复报错；
- 生成测试；
- 写开发说明。

## AI 工具不应独立决定什么

- 采购合规边界；
- 供应商敏感资料是否公开；
- 正式上线安全判断；
- 微信审核材料；
- 商业报价策略；
- 消防业务正确性。

## 推荐组合

- ChatGPT：产品规划、文档、提示词、业务拆解；
- Codex：代码实现、Git 工作流、调试；
- 微信开发者工具：小程序验收；
- Antigravity/Figma：UI 微调；
- 人工：业务和合规最终判断。

## 成本提醒

除了 AI 订阅费，还需要考虑：

- 小程序认证；
- 域名；
- HTTPS；
- 云服务器；
- 数据库；
- 对象存储；
- 内容审核；
- 备份与监控；
- 真实数据整理；
- 人工测试。
