# 开发术语速查表｜给非程序员

## 前端

用户看得见的界面。微信小程序页面就是前端。

## 后端

用户看不见的服务器程序，负责查数据库、校验权限、返回数据。

## API

前端和后端之间的“取数据通道”。例如小程序请求 `/products`，后端返回装备列表。

## 数据库

结构化存储数据的地方，例如产品、供应商、中标记录、用户、询价线索。

## Mock 数据

假的样例数据，用于真实数据没准备好时先跑通页面。

## Git

代码版本管理工具，可以保存历史、回退错误、开分支实验。

## 分支 Branch

独立开发路线。一个功能一个分支，避免改乱主线。

## 工作树 Worktree

同一个项目的独立工作区，适合长期模块并行开发。

## PRD

产品需求文档，说明做什么、不做什么、给谁用、怎么验收。

## MVP

最小可行产品。第一版只做最核心闭环，不做全部梦想功能。

## CRUD

增删改查：Create、Read、Update、Delete。

## RBAC

基于角色的权限控制。你的项目至少有普通用户、消防认证用户、供应商、平台管理员。

## 对象存储

存图片、PDF、证书、报告的云存储。数据库只存文件地址，不存文件本体。

## 合法域名

微信小程序正式环境只能请求后台配置过的 HTTPS 域名。

## CI

自动检查流程，例如每次提交后自动运行 lint、typecheck、test。
