# 微信开发者工具联调说明

## 作用

微信开发者工具不是最后上线才用，而是从第一天就参与开发。它负责验证 Codex 写出的小程序页面在真实微信环境里是否能运行、是否适合手机、是否符合小程序限制。

微信小程序运行在微信生态内，不需要用户额外下载安装；开发调试通常需要微信开发者工具。相关背景可参考微信小程序公开资料中对开发工具与平台形态的介绍。

## 推荐联调流程

```txt
Codex 写代码
↓
本地启动小程序编译
↓
微信开发者工具导入编译目录
↓
电脑模拟器查看
↓
手机微信扫码真机预览
↓
记录问题
↓
把问题结构化反馈给 Codex
↓
修复后 Git 提交
```

## 你要检查什么

### 页面基础

- 页面是否白屏；
- 控制台是否有红色报错；
- Tab 是否能切换；
- 搜索框是否能输入；
- 按钮是否容易点击；
- 字体是否过小；
- 微信右上角胶囊区域是否被遮挡；
- iPhone 和安卓模拟器是否都正常；
- 真机是否可读、可点、不卡顿。

### 业务重点页面

1. 选装首页；
2. 产品详情页；
3. 参数对比页；
4. 供应商工作台；
5. 供应商线索详情页。

## 常见问题解释

### 合法域名

正式小程序不能随便请求本地地址或临时 IP。后端接口必须配置到微信小程序后台的 request 合法域名，并使用 HTTPS。

### API

API 是小程序和后端之间取数据的接口。例如小程序请求 `/products`，后端返回装备列表。

### Mock 数据

Mock 数据是假数据，用来在真实数据库还没准备好时先把页面跑通。

### 真机预览

开发者工具模拟器正常不代表手机正常。每个核心页面必须扫码真机预览。

```txt
【粘贴红色报错】

【接口地址、状态码】

请只修复相关问题，不要重构无关代码。修复后说明原因，并运行 lint/typecheck/test。
```
