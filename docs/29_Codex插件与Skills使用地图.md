# Codex 插件与 Skills 使用地图

## 总体理解

插件是 AI 可调用的外部能力，Skills 是封装好的工作流程。它们不是按钮合集，而是帮助你完成产品定位、场景建模、UI 设计、商业表达和开发执行的工具箱。

## 对本项目最有价值的 Skills

| Skill | 作用 | 本项目使用场景 |
|---|---|---|
| Positioning | 定位分析 | 明确消防用户、采购人员、供应商、平台运营方 |
| Scene explorer | 场景设计 | 高层火灾、地下空间、城市内涝、水域救援等 |
| Explore | 结构探索 | 装备分类、参数模板、行业数据结构 |
| Moodboard | 情绪板 | 统一消防科技风/工业装备风 UI |
| Shot explorer | 画面结构 | 首页 Banner、产品卡、详情页结构 |
| Generative polish | UI 优化 | 降低信息密度、优化手机端可读性 |
| Offer explorer | 卖点结构 | 产品详情页和供应商介绍 |
| Ads explorer | 广告分析 | 供应商推广、首页专题、品牌展示 |
| Apollo/CRM 类 | 供应商线索 | 建供应商库、冷启动邀约 |

## 推荐使用顺序

```txt
Positioning + Scene + Explore
↓
Moodboard + Shot + Polish
↓
Offer + Ads
↓
Codex 写代码
```

## 关键提醒

插件适合先把业务结构想清楚，不要一打开 Codex 就写代码。真正开发前，应先确定用户角色、装备分类、场景模型、数据字段、UI 密度规则。
