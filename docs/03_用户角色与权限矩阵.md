# 03_用户角色与权限矩阵

| 角色 | 权限范围 | 限制 |
|---|---|---|
| 游客 | 浏览首页、部分产品、部分帖子 | 不可询价、评论、下载资料 |
| 注册用户 | 收藏、评论、浏览完整基础信息 | 不可查看敏感招采参考 |
| 消防认证用户 | 询价、索取资料、对比、下载、评价 | 需通过认证 |
| 供应商普通员工 | 查看分配线索、查看产品状态 | 不可修改企业认证主体 |
| 供应商管理员 | 管理企业资料、产品、线索、员工 | 只能管理本企业数据 |
| 专家/达人 | 发布专业内容、答疑、参与点评 | 需平台认证 |
| 平台管理员 | 审核、配置、管理、处理举报 | 所有操作留痕 |

## 关键规则

1. 供应商不能默认看到消防用户手机号。
2. 消防用户提交询价后，供应商先通过平台内线索系统跟进。
3. 产品未审核不得公开展示。
4. 供应商内容必须标记“供应商发布”。
5. 用户评价、供应商宣传、平台核验三类内容必须区分展示。
