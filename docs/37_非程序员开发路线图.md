# 非程序员开发路线图

## 你的核心身份

你不是来亲自写每一行代码的，而是项目负责人、产品定义者、业务验收人。Codex 是执行工具，不是决策者。

## 第 0 阶段：准备

1. 下载本迁移包；
2. 解压到本地；
3. 建 Git 仓库；
4. 用 Codex 打开项目；
5. 第一轮只让 Codex 阅读文档。

## 第 1 阶段：项目骨架

目标：能启动小程序、后端、后台空页面。

你要验收：

- 目录是否清晰；
- package scripts 是否能运行；
- 小程序能否被微信开发者工具导入；
- 后端能否启动；
- 没有业务功能也没关系。

## 第 2 阶段：数据库

目标：产品、供应商、分类、参数模板、询价线索、审核记录表建立。

你要验收：字段是否能表达消防业务。

## 第 3 阶段：后端 API

目标：产品列表、详情、分类、供应商、线索、对比等接口。

你要验收：接口返回的数据是否符合页面需要。

## 第 4 阶段：供应商 PC 后台

目标：供应商能认证、录产品、上传资料、看线索。

## 第 5 阶段：平台后台

目标：平台能审核供应商、审核产品、处理举报、看日志。

## 第 6 阶段：小程序核心链路

目标：选装首页、产品详情、参数对比、询价线索跑通。

## 第 7 阶段：微信联调

目标：微信开发者工具模拟器和真机预览可用。

## 第 8 阶段：数据冷启动

目标：用公开资料预建产品库，邀请供应商认领。

## 每日工作法

```txt
git status
↓
确认当前分支
↓
给 Codex 一个小任务
↓
运行检查
↓
微信开发者工具验收
↓
记录问题
↓
修复
↓
git commit
```
