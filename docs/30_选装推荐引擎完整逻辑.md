# 选装系统完整逻辑：消防装备版推荐引擎

## 本质

选装系统不是商品列表，而是：

> 基于任务场景的装备决策系统。

## 总体结构

```txt
场景层 Scene Layer
↓
规则层 Rule Layer
↓
推荐层 Ranking Layer
↓
装备组合 Solution Package
```

## 场景层

一级场景：

- 火灾类：高层建筑、地下空间、工业厂房、森林火灾；
- 水域类：洪水、激流、城市内涝；
- 城市救援：交通事故、倒塌建筑；
- 特殊环境：隧道、化工事故。

用户输入：

- 场景类型；
- 地形条件；
- 风险等级；
- 人员规模；
- 水源条件；
- 建筑高度；
- 预算范围。

## 规则层

```ts
Rule {
  scene_id: string
  required_capabilities: string[]
  preferred_equipment: string[]
  forbidden_equipment: string[]
  weight_factor: number
}
```

示例：高层建筑火灾

- 必须能力：高压供水、举高救援、高空破拆；
- 推荐装备：云梯消防车、举高喷射消防车、高压水罐车；
- 不推荐：低压供水车辆作为主力装备。

## 推荐评分

```txt
Score = 场景匹配度 40%
      + 参数匹配度 25%
      + 中标频率 20%
      + 供应商可靠度 10%
      + 平台热度 5%
```

第一版可以先做规则 + 权重 mock，不必上复杂机器学习。

## 推荐结果

系统输出装备组合，而不是单个产品。

```json
{
  "scene": "城市内涝",
  "recommendations": [
    {
      "equipment": "大流量排水抢险车",
      "score": 92,
      "reason": "适合城市道路和地下空间快速排涝",
      "parameters_match": "90%"
    }
  ]
}
```

## 开发顺序

1. 建 Scene 表；
2. 建 Capability 表；
3. 产品绑定能力标签；
4. 建 Rule 表；
5. 实现 `/recommend` API；
6. 小程序选装页接入；
7. 推荐结果支持加入对比和采购清单。
