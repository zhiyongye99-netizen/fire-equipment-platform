# 18_V3决策变更记录

## 相比 V2 的重要变更

1. 补充供应商小程序轻工作台，并明确它不是供应商 PC 后台的替代品。
2. 供应商工作台从高密度后台型界面，调整为低密度任务型首页。
3. 选装页顶部目录改为“车辆、灭火、水域、无人装备”等一级目录简称。
4. 选装页移除平台 Logo 和大标题。
5. 选装页快捷入口只保留“分类筛选”和“参数对比”。
6. 页面设计统一执行低密度、手机可读优先原则。
7. 产品详情页从高密度采购证据页，调整为首屏大图 + 关键参数 + 分段展开。
8. 设计参考图统一放入 design-references/。
9. 建议底部导航仍使用：首页、消防圈、选装、我的。供应商工作台从我的进入，除非后期决定给供应商角色动态显示“供应商”Tab。

## 当前仍需人工确认

1. 小程序名称最终叫“消防装备智选”还是其他名称。
2. 顶部一级目录第一版保留哪些类目。
3. 是否允许供应商角色底部动态显示“供应商”Tab。
4. 供应商是否能在小程序端修改产品基础信息。
5. 首页资讯来源和转载授权机制。
