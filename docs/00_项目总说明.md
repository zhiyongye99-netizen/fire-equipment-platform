# 00_项目总说明

## 一、项目定位

“消防装备智选”是面向中国消防车辆装备领域的专业微信小程序和后台系统，提供消防行业资讯、装备查询、参数比选、采购前决策辅助、消防圈社区、供应商产品展示和线索连接。

## 二、服务对象

1. 消防指战员、装备采购骨干、战训骨干。
2. 企业专职消防队、民间救援队。
3. 消防车辆、器材、信息化、无人装备、维保服务供应商。
4. 消防专家、装备达人、培训机构。
5. 平台运营管理人员。

## 三、产品边界

本系统定位为“采购前决策辅助平台”。它不替代政府采购平台，不直接承接招标、评标、合同签订、资金支付，不输出正式招标文件。

## 四、核心价值

- 对消防用户：降低装备信息搜索、参数比选、价格参考、供应商初筛成本。
- 对供应商：合规展示产品能力，获取经过平台留痕的有效线索。
- 对平台：沉淀装备分类、参数模板、招采参考、用户评价和供应商资料库。

## 五、三端结构

1. 微信小程序：消防用户端 + 供应商轻工作台。
2. 供应商 PC 后台：产品录入、资质资料、线索管理。
3. 平台运营后台：审核、内容、分类、参数模板、运营配置。
