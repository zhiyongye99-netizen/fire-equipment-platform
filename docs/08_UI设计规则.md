# 08_UI设计规则

## 设计定位

专业、干净、可信、适合中国消防业务场景。避免炫技、过度拟物、PC 后台化。

## 手机端规格

| 项目 | 建议 |
|---|---|
| 页面主标题 | 34–38rpx |
| 卡片标题 | 30–32rpx |
| 正文 | 28–30rpx |
| 辅助文字 | 不低于 24rpx |
| 按钮高度 | 72–88rpx |
| 一屏模块数 | 3–4 个以内 |
| 信息流卡片 | 每屏 2–3 条 |

## 低密度原则

小程序端不是展示全部信息，而是帮助用户快速完成当前动作。

- 首页：看新闻、搜装备、进选装。
- 选装：选分类、看产品、对比、询价。
- 产品详情：看大图、关键参数、供应商、询价。
- 供应商工作台：看线索、回线索、看审核、处理消息。

## 底部导航

第一版建议固定为：

- 首页
- 消防圈
- 选装
- 我的

供应商工作台建议从“我的”进入。若后期供应商用户占比显著增加，再考虑为供应商角色动态显示“供应商”Tab。
