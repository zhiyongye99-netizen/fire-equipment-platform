# 线上服务架构与部署准备清单

## 关键认知

微信小程序只是前端界面。完整系统还需要后端 API、数据库、文件存储、管理后台、域名、HTTPS、日志、备份和权限系统。

## 第一版推荐架构

```txt
微信小程序前端
↓
NestJS 后端 API
↓
PostgreSQL 数据库
↓
对象存储 COS/OSS
↓
Next.js 供应商后台 + 平台后台
↓
云服务器/云托管 + HTTPS 域名
```

## 必备服务

| 服务 | 是否必须 | 说明 |
|---|---|---|
| 微信小程序账号 | 必须 | 建议企业主体 |
| 微信认证 | 建议 | 企业服务类更稳妥 |
| 域名 | 必须 | api.xxx.com、admin.xxx.com |
| HTTPS | 必须 | 正式小程序请求必须 HTTPS |
| 云服务器 | 必须 | 后端和后台部署 |
| 数据库 | 必须 | PostgreSQL 或 MySQL |
| 文件存储 | 必须 | 图片、PDF、证书、报告 |
| 日志监控 | 必须 | 排查错误与安全留痕 |
| 数据备份 | 必须 | 防止资料丢失 |
| 内容审核 | 建议 | 消防圈、评论、供应商发布 |
| 微信支付 | 暂缓 | 第一版不做交易闭环 |

## 不要第一版做的事项

- 在线交易；
- 二手装备交易；
- 自动生成正式招标文件；
- 自动推荐中标供应商；
- 微信支付；
- 大规模 AI 商机预测。

## 三套环境

```txt
local      本地开发
staging    测试体验版
production 正式上线
```

小程序代码里不要写死接口地址，应通过环境配置切换。
