# 可开发级 UI 结构图：四大微信小程序页面

## 首页 Home

```txt
Page: Home
├── TopBar
│   ├── SearchInput：搜索车辆/装备/中标/供应商
│   └── MessageEntry：消息入口，不占微信胶囊区域
├── CategoryGrid
│   ├── 车辆
│   ├── 灭火
│   ├── 水域
│   ├── 排涝
│   ├── 无人装备
│   ├── 通信指挥
│   ├── 防护
│   └── 检测
├── ChannelTabs
│   ├── 要闻
│   ├── 装备
│   ├── 中标
│   └── 案例
├── FeedList
│   ├── NewsCard
│   ├── BidCard
│   ├── ProductCard
│   └── SupplierCard
└── BottomTab：首页/消防圈/选装/我的
```

## 消防圈 FireCircle

```txt
Page: FireCircle
├── ChannelTabs：推荐/装备讨论/实战案例/经验分享/供应商动态
├── TopicFilter：水域/排涝/车辆/无人装备/采购避坑
├── PostList
│   ├── author
│   ├── content
│   ├── images
│   ├── scene_tags
│   ├── related_product
│   └── like/comment/share
├── FloatingPublishButton
└── BottomTab
```

## 选装 SelectionSystem

```txt
Page: SelectionSystem
├── CategoryBar：车辆/灭火/水域/排涝/无人装备/通信
├── SearchInput
├── QuickActions
│   ├── 分类筛选
│   └── 参数对比
├── BrandStrip：品牌 Logo 横滑
├── HotKeywords：热门搜索词
├── SceneSelector：火灾/城市内涝/水域/隧道/危化
├── ProductList
│   └── ProductCard
│       ├── image
│       ├── name
│       ├── core_parameters 2-3 个
│       ├── tags
│       ├── reference_price
│       ├── compare_button
│       └── inquiry_button
├── CompareFloatingBar：已选 N 个，去对比
└── BottomTab
```

## 我的 Mine

```txt
Page: Mine
├── UserCard
│   ├── avatar
│   ├── name
│   ├── role：消防用户/供应商/平台管理员
│   └── certification_status
├── Stats：收藏/对比/询价/浏览
├── ServiceGrid
│   ├── 我的收藏
│   ├── 对比记录
│   ├── 询价记录
│   ├── 采购清单
│   ├── 资料下载
│   └── 浏览历史
├── WorkbenchEntry
│   ├── 采购助手
│   └── 供应商工作台
├── Settings：账号/通知/隐私/帮助
└── BottomTab
```

## 组件复用规则

- `ProductCard` 全站统一；
- `SupplierCard` 全站统一；
- `BidCard` 全站统一；
- 图片仅作为视觉参考，字段以 API 和数据库为准。
