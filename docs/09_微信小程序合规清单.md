# 09_微信小程序合规清单

## 内容合规

- 资讯内容应注明来源。
- 供应商内容必须标识“供应商发布”。
- 用户评论、评价、帖子必须支持举报和审核。
- 不得发布未经核验的夸大宣传和绝对化表述。

## 交易边界

- 不做政府采购交易闭环。
- 不做在线支付采购。
- 不做自动评标。
- AI 输出只作为采购前参考，不作为正式招标文件。

## 隐私合规

- 消防用户手机号不默认暴露给供应商。
- 供应商联系人信息按企业授权展示。
- 上传资料应区分公开、授权、内部参考、敏感资料。

## 技术规范

- 小程序端不使用浏览器 DOM API。
- 不使用 localStorage，使用小程序/Taro 存储 API。
- 使用分包控制体积。
- 敏感逻辑放后端，不放前端。
