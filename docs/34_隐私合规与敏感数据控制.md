# 隐私合规与敏感数据控制

## 关键原则

你的项目涉及消防用户、供应商、采购意向、联系方式、产品资料和线索。权限和隐私必须从第一版就设计。

## 不能放前端的内容

- AppSecret；
- 数据库连接字符串；
- 管理员 token；
- 供应商未授权资料；
- 用户完整手机号；
- 报价底线；
- 内部招标文件；
- 证书私密原件。

## 供应商资料可见范围

1. 公开展示；
2. 消防认证用户可见；
3. 申请后可见；
4. 仅平台审核可见；
5. 不采集。

## 小程序隐私提示

涉及用户信息、手机号、单位、浏览行为、资料申请等功能时，应有隐私政策和用户授权逻辑。

## 操作日志

必须记录：

- 谁审核了供应商；
- 谁审核了产品；
- 谁查看了敏感资料；
- 谁导出了数据；
- 谁修改了权限；
- 谁关闭了线索。

## 不要做的高风险功能

- 私下撮合规避采购流程；
- 自动生成带排他性参数的招标文件；
- 对供应商做官方背书式排名；
- 暴露消防用户完整联系方式；
- 公开未授权检测报告原件。
