# 16_Image2_UI设计工作流与提示词

## 定位

Image 2.0 生成的是 UI 概念图，用于确定视觉方向和界面结构，不是最终可编辑设计稿，也不是代码。

## 建议输出页面

1. 首页。
2. 选装首页。
3. 我的。
4. 消防圈。
5. 产品详情。
6. 参数对比。
7. 供应商小程序工作台。

## 已形成的重要设计决策

- 微信小程序右上角胶囊位置必须留给微信系统，不放自定义按钮。
- 选装页不显示“消防图标”和“消防装备智选”标题。
- 选装页顶部目录使用“车辆、灭火、水域、无人装备”等简称。
- 选装页快捷入口只保留“分类筛选”“参数对比”。
- 手机端全部页面降低信息密度、放大字号、增加留白。
- 供应商小程序工作台采用低密度任务型结构。
