# 商业模式第一性原理分析

## 根本问题

消防车辆装备采购是高金额、低频次、高责任、高专业门槛、信息高度不对称的决策。

这个项目有商业价值，但第一阶段不应定位为“消防装备电商”或“消防版汽车之家”，而应定位为：

> 消防车辆装备采购前决策辅助平台。

## 价值公式

```txt
商业价值 = 高责任场景 × 信息不对称 × 数据结构化能力 × 供应商付费意愿 × 平台信任度
```

## 真正有价值的部分

1. 装备参数库；
2. 中标价格参考库；
3. 产品实战评价库；
4. 供应商线索撮合系统；
5. 采购前决策辅助工具。

## 付款方判断

消防用户有需求，但第一阶段未必直接付费。供应商是更现实的第一阶段付款方。

供应商愿意为以下内容付费：

- 认证会员；
- 产品展示增强；
- 线索服务；
- 数据报告；
- 品类专题；
- 采购前资料整理服务。

## 三阶段路径

### 阶段一：工具型平台

装备库、参数对比、产品详情、供应商后台、平台审核、询价线索。

### 阶段二：数据型平台

中标价格区间、热门品类趋势、区域采购趋势、供应商竞品分析。

### 阶段三：决策辅助平台

AI 采购需求草稿、参数排他性风险提示、采购清单、供应商信用画像。

## 不宜第一版做

- 交易佣金作为核心；
- 在线交易；
- 自动生成正式招标文件；
- 自动推荐中标供应商；
- 二手装备交易。
